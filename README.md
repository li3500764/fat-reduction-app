# 🥗 减脂餐记录 (Fat Reduction App)

一个轻量级、注重隐私的纯前端减脂饮食记录工具。
无需注册登录，数据完全存储在本地浏览器。结合 DeepSeek AI 智能估算食物热量，助你轻松管理每日摄入。

🔗 **在线体验**: [https://li3500764.github.io/fat-reduction-app/](https://li3500764.github.io/fat-reduction-app/)

## ✨ 主要功能

- **📝 极简记录**: 快速添加早午晚餐及加餐，清晰直观。
- **🤖 AI 智能估算**: 接入 DeepSeek API，输入“一个鸡蛋和一杯牛奶”即可自动计算热量。
- **🔒 隐私安全**: 所有数据（饮食记录、API Key、身体数据）均存储在本地 (LocalStorage)，不上传任何服务器。
- **📅 日历视图**: 方便回顾历史饮食情况，热量达标情况一目了然。
- **📊 进度追踪**: 实时显示今日摄入与目标热量的进度对比。
- **📤 分享打卡**: 生成精美的饮食打卡图片，一键分享给好友。

## 🚀 使用指南

1.  打开 [在线链接](https://li3500764.github.io/fat-reduction-app/)。
2.  **设置 API Key** (推荐):
    - 点击右上角设置图标 ⚙️。
    - 输入您的 DeepSeek API Key (国内可用，价格亲民)。
    - _注：没有 Key 也可以手动输入热量使用。_
3.  **完善个人信息**: 首次使用输入身体数据，AI 将为您推荐每日热量目标。
4.  开始记录您的每一餐！

## 🛠️ 技术栈

- 原生 HTML / CSS / JavaScript
- DeepSeek API (AI 能力支持)
- html2canvas (图片生成)
